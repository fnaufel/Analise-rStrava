# 3. User interacts with system through a menu

Date: 2025-09-19

## Status

Accepted

## Context

Although reports will be the main output of the system, we do not want
the user to have to open, edit and execute the qmd files.

## Decision

Base interaction on a main menu, possibly with submenus. Implement a
controller for this.

## Consequences

It becomes clearer what the actions are.
